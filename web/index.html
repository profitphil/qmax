QMax: the Qubic DEX aggregator

QMax is a non-custodial trading terminal and liquidity router for Qubic. It compares the QX order book with the QSwap pool and splits your order across both for the best price. It is free, and every trade is signed in your own wallet. It needs JavaScript to run.

  • Charts with live candles, indicators and drawing tools for every asset on QX and QSwap.
  • Swap QU for tokens, a portfolio, QSwap pools ranked by the fees they earn, and a Discord bot.
  • How much would a sale fetch? GET /api/v1/quote?side=sell&asset=QDOGE&qty=1000000 prices an order across QX and QSwap and says the result in words. Free, no key, no wallet needed.
  • Live prices, order books and what a sale would fetch for every Qubic token and share: all tokens.
  • New to trading on Qubic? Read how QX, QSwap and QMax work, what they cost, and which to use.
  • For AI agents: an HTTP API with an OpenAPI document, x402 payment rails (Q+Pay, settled through QPayhub) and a plain-text guide at /llms.txt, and a downloadable MCP server and TypeScript SDK.
